# Video tells

Compare frames at 0, 25, 50, 75 and 100%: the product, any logo and any face must be the same in all of them. A generated clip is a three-to-eight-second beat (a product close-up, a setting, a reveal), never the whole ad, and never a person standing in for the owner or a customer.

| Trope | Fix |
|---|---|
| Temporal morphing: objects, faces, logos, products change between frames (Coca-Cola's truck) | Keep generated shots to 4 to 8 s of b-roll. Never generate the product, logo or a recurring character |
| Background "boiling": foliage, crowds, architecture shimmer; flicker in static regions | Locked-off or real footage for anything held on screen |
| Physics faked: water, smoke, fabric, rain droplets all one size; objects passing through each other | Avoid fluids and contact shots in generated clips |
| Excessively smooth, floaty camera motion; endless slow push-ins | Cuts, handheld owner footage, a static frame |
| Uncanny avatars: symmetric faces, off-timed microexpressions, lip-sync drift, odd gaze | No synthetic presenters. The owner on a phone beats a perfect avatar |
| Stitched-clip incoherence: disjointed scenes, no through-line (McDonald's NL) | One idea per video, a scripted hook (proposition in 3 s) and a real CTA |
| Tone mismatch (cynical or dark for a warm brand) | The brand's voice notes set tone |
| Garbled on-screen text inside the generated frame | Ask the video model for no text; captions and the call to action go on in the edit |
| Generic stock-motif b-roll | The owner's clips first (`media/clips`), generated last |
